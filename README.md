# -krestiki-noliki
1. Игра только запущена. Поле 3×3 полностью пустое. Внизу отображается текущий ход — X (первый игрок). Первая клетка выделена синей рамкой, показывая, что она находится в фокусе. Игрок готов сделать первый ход.
   <img width="415" height="460" alt="image" src="https://github.com/user-attachments/assets/cedc997e-ea03-425c-b68e-be74cbb94667" />
2. Игрок X поставил крестик в верхнюю левую клетку. Теперь ход переходит к игроку O — об этом сообщает надпись «Ход O» внизу. Синяя рамка переместилась на следующую клетку, ожидая действия второго игрока
   <img width="414" height="461" alt="image" src="https://github.com/user-attachments/assets/80485342-4b9d-4da7-a7d6-12fdeb847b1f" />
3. На поле уже два символа: X в левом верхнем углу и O в центре. Сейчас ход снова у игрока X. Синяя рамка выделения находится на клетке в правом столбце второго ряда — игрок выбирает, куда поставить следующий крестик.
    <img width="408" height="455" alt="image" src="https://github.com/user-attachments/assets/0d36afe5-a134-4ee0-8505-d9efa15e6ec3" />
4. Игрок X выиграл, собрав три крестика в верхнем ряду (горизонтальная линия). На экране появилось сообщение «Игрок X выиграл!». Игра завершена, но поле остаётся видимым, чтобы игрок мог увидеть выигрышную комбинацию. Кнопка «начать заново» выделена синей рамкой.
    <img width="412" height="458" alt="image" src="https://github.com/user-attachments/assets/8c37af11-9861-4fce-aa15-5cd566067734" />
5. Все 9 клеток поля заполнены, и ни одному из игроков не удалось собрать три символа в ряд. На экране отображается сообщение «Ничья!». Это классический результат при оптимальной игре обоих соперников. Кнопка «начать заново» предлагает начать новую партию.
    <img width="411" height="462" alt="image" src="https://github.com/user-attachments/assets/715beb33-724d-49ae-96c0-ebdee622c613" />
